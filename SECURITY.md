# Security

The mod is designed for a **trusted LAN**. Its UDP protocol is neither
encrypted nor authenticated, and a peer on your network can send it game
state. Never forward its port to the Internet.

To report a vulnerability, for example a packet that crashes the game or
corrupts memory, use
[GitHub's private vulnerability reporting](https://github.com/DrSkunk/theys-gone/security/advisories/new)
instead of a public issue.
