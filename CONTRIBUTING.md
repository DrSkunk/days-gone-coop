# Contributing

Thanks for helping! Bug reports, game-tested fixes and research notes are all
welcome.

## Before you start

- Read [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) and
  [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
- Don't commit game files, executables, assets, saves, logs or credentials.
- Only use code you're allowed to share under the MIT license. Don't copy
  code or assets from mods whose terms don't allow it.

## Pull requests

1. Keep changes focused, and run `make test build` before you push.
2. Use [Conventional Commits](https://www.conventionalcommits.org/) for your
   commit messages: `feat:`, `fix:`, `docs:`, `ci:`, …. They drive versioning
   and the changelog. Mark protocol-incompatible changes with `!`.
3. Say what you tested in the game: OS or Proton version, single game or two
   games, and what you saw. Say clearly what you didn't test.
4. Update the README or docs when behavior or settings change.

## AI-assisted contributions

This project was itself developed largely with AI assistants, and AI-assisted
contributions are welcome. Mention it in the pull request. You're responsible
for reviewing, testing and understanding everything you submit.
